# brand

`brand:brand` is the CLI `brand.sh`, package `brand_tool`, plus the bundled brands in `brands/` and the maintainer
script `scripts/build_neutral_pptx.py`. The brand folder format is in the skill's `SKILL.md`.

## Code

`config.py` holds the lookup and `cli.py` the argparse commands `list`, `show` and `copy`. The CLI depends only on
`plugin_settings`, which reads the one setting, `brand.path` (a list of directories), from `config.yaml`.

`search_dirs` returns the bundled `brands/` directory, then each `brand.path` entry (`~` expanded by the schema),
skipping entries that are not directories, and directories already listed (compared after resolving symlinks). `find`
returns the first `<dir>/<name>/` holding a `brand.yaml`; `list_brands` keeps the first folder per name and skips a
directory it cannot read. A name that is empty, `.`, `..` or contains a path separator is rejected. Every failure is a
`BrandError`, printed to stderr with exit status 1 and the list of searched directories.

`copy` refuses a source and target that contain each other, compared after resolving the source and the destination
directory but not the target itself, so a symlink at the target is replaced, never followed. It copies into a
temporary directory inside the destination first and renames that into place, so a failed copy leaves an existing
target intact.

## Neutral PowerPoint template

`brands/neutral/pptx/presentation.pptx` is generated by `build_neutral_pptx.py` from the python-pptx default template;
the run command is in the script's docstring and needs the `build` dependency group of the skill project. The script:

- sets the slide size to 16:9 (12192000 x 6858000 EMU) and scales the x offset and width of every master and layout
  shape by the width ratio, leaving vertical geometry unchanged;
- keeps the layouts "Title Slide", "Section Header", "Title and Content", "Two Content" and "Blank", in that order, and
  no slides;
- writes the theme colour scheme from `colors` of `neutral/brand.yaml` and the major and minor fonts from `fonts`
  `heading` and `body`. Theme slots the brand does not name are derived from its other colours;
- removes `cap="all"` from master and layout runs, so the Section Header title keeps the case of its text;
- fixes the core property dates and the zip timestamps, so the same python-pptx version gives the same bytes.

`presentation.json` beside it is the `inspect-template` output of `docs:pptx`; the build script does not write
it. `docs:pptx` takes its default chart colours (`CHART_COLORS`) from the neutral accents; a change of those
colours in `brand.yaml` does not reach it.

## Tests

`tests/unit/brand/test_brand.py` runs every lookup in a child process with a written `config.yaml`. It checks the
search order, `brand.path`, the `copy` refusals and replacements, and the CLI output and exit codes. The
conformance tests check each bundled brand and the test brand `tests/brands/acme` against the `brand.yaml` table of
`SKILL.md`: allowed keys, existing files, colour and font formats, the palette keys, `caption` numbers, `pptx` entries
and `styles` names. A test also checks that the key table of `SKILL.md` lists exactly the keys the conformance tests
check. `TestNeutralPptx` reads the neutral template's zip directly and checks its size, the absence of slides, the
layout names and order, and that the theme matches `brand.yaml`.
