# docs

Maintainer documentation. Agent-facing documentation is in each skill's `SKILL.md` and `references/`.

- [architecture.md](architecture.md): the repository rules, their reasons and the tests that enforce them.
- [ai_models.md](ai_models.md): `lib/ai_models`, every model call of the skills, its providers and model routes.
- [plugin_settings.md](plugin_settings.md): `lib/plugin_settings`, the settings file `config.yaml` and the plugin data directories.
- [brand.md](brand.md): `brand:brand`, brand folders and their lookup.
- [style.md](style.md): `brand:style`, the catalogue of visual styles.
- [classify.md](classify.md): `ai:classify`, text classification and scoring.
- [second-opinion.md](second-opinion.md): `ai:second-opinion`, file review by a non-Claude model.
- [pptx.md](pptx.md): `docs:pptx`, the raw `.pptx` operations CLI.
- [revealjs-slideshow.md](revealjs-slideshow.md): `docs:revealjs-slideshow`, offline reveal.js presentations.
- [image-gen.md](image-gen.md): `media:image-gen`, image generation and editing.
- [music.md](music.md): `media:music`, music generation and clip checks.
- [pptx-author.md](pptx-author.md): `media:pptx-author`, its design library.
- [short-video.md](short-video.md): `media:short-video`, film projects, scenes and rendering.
- [video-effects.md](video-effects.md): `media:video-effects`, image-to-image transition clips.
- [voiceover.md](voiceover.md): `media:voiceover`, narration audio and timings.
- [studio.md](studio.md): the `studio` plugin, its web page, server and skills.
