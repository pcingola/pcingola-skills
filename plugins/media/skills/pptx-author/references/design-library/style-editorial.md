# Style — Editorial Big-Number

Catalogue style: `editorial-big-number` from `brand:style`. Its style line and the
deck's palette are the first line of every prompt (see `infographic.md`).

Guide image: `style-editorial.png`

## When to use

Sequences and ranked lists where the steps/points themselves are the content
(a numbered plan, a top-N list, a short narrative arc). Avoid for content
that's inherently grid-like (many parallel items, comparisons) — use Minimal
Enterprise or Bold Color Block for those instead.

## Header line (brand is a slot, not baked in)

> Top-left header, small and subtle: bold `accent1` text "{PROJECT / DECK
> TITLE}", then lighter grey small text "{SLIDE LABEL}". [Add a brand mark
> only if the deck calls for one; omit for brand-neutral use.]

## Subtitle line (the assertion)

> Below the header, one short bold subtitle line in `dk1`, set large and
> left-aligned like a magazine pull-quote: "{ONE-LINE CLAIM}".

## Closing line (paste verbatim, last line before Negative)

> Extremely clean, elegant, spacious, confident typographic hierarchy. All
> text correctly spelled and crisp.

## Negative block

> neon, glow, dark background, greek columns, 3d, photorealistic, busy,
> cluttered, gibberish, misspelled, heavy gradients, drop shadows, large logo,
> boxed cards

## Center layout

Oversized pale `accent1` numerals ("01", "02", "03"…) in a loose column, each
paired with a bold short title, one line of `dk1` descriptive text, and
one small line icon floating beside the title. A thin horizontal hairline
rule separates each row — no card borders or boxes. Works with 3–5 items; more
than that, switch styles.

## Design tokens

Colours and fonts from the deck's brand (`brand:brand`), else the `neutral` brand.
Icons: same small minimal line-icon vocabulary as the other styles, just untethered
from a card.
