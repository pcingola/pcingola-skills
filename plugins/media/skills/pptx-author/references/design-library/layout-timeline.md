# Layout — Timeline / Roadmap

Guide image: `layout-timeline.png`

Center layout **G** (extends `infographic.md`'s A–E). A horizontal timeline line with
alternating milestone cards.

## When to use

Roadmaps, phased plans, anything with a "what happens when" structure.

## Center layout

A thin horizontal `accent1` line spanning the width, with evenly spaced small filled
circular nodes along it. Each node connects via a thin vertical line to a small white
card containing a bold date/quarter label, one short title, and one grey caption line.
Cards alternate above and below the timeline line for readability.

## Design tokens

Colours and fonts from the deck's brand (`brand:brand`), else the `neutral` brand.
Pairs with any of the 3 styles in this directory (`style-minimal.md`,
`style-editorial.md`, `style-colorblock.md`).
