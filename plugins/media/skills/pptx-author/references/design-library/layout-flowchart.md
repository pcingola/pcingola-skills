# Layout — Flowchart

Guide image: `layout-flowchart.png`

Center layout **H** (extends `infographic.md`'s A–E). Boxes and arrows with a branch.

## When to use

Process or decision logic that isn't a straight line — contrast with layout C
(Horizontal pipeline) in `infographic.md`, which is a straight sequence with no
branching.

## Center layout

Small white rounded rectangle boxes connected by thin arrows: an input box, one
diamond-shaped decision box that branches into two paths, each path leading to its own
box, both paths reconverging into a final output box. One small line icon per box.

## Design tokens

Colours and fonts from the deck's brand (`brand:brand`), else the `neutral` brand.
Pairs with any of the 3 styles in this directory (`style-minimal.md`,
`style-editorial.md`, `style-colorblock.md`).
