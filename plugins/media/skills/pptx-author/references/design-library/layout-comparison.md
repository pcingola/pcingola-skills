# Layout — Comparison Split

Guide image: `layout-comparison.png`

Center layout **I** (extends `infographic.md`'s A–E). Two columns divided by a hairline.

## When to use

Trade-offs, before/after, option A vs. option B — any two-sided comparison.

## Center layout

Two equal-width vertical columns divided by a thin vertical hairline rule down the
center. Each column headed with a bold title (one in `accent1`, one in `accent3`) followed by short
bullet lines, each with a small line icon. No card borders around the columns — only
the center divider.

## Design tokens

Colours and fonts from the deck's brand (`brand:brand`), else the `neutral` brand.
Pairs with any of the 3 styles in this directory (`style-minimal.md`,
`style-editorial.md`, `style-colorblock.md`).
