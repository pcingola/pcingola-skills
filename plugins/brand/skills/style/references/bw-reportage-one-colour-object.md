# BW Reportage One Colour Object

## Style line

Documentary black-and-white photograph, full-frame camera, fine natural film grain, rich tonal range from deep charcoal to clean white, in the tradition of Magnum reportage and annual-report portraiture: a candid, unposed moment, nobody looks at the camera, the whole image is monochrome except exactly one object, rendered in a matte, muted colour, not glowing

## Default palette

monochrome, the one object in a muted deep teal

## Result

No text in the image; HTML caption cards with one teal rule.

## Avoid

A composited colour screen has to be desaturated or kept as the frame's second colour element.

## Suits

Suits a short film with a documentary tone and one object as the subject.
