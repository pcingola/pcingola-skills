# Dark HTML Render

## Style line

Dark application screen or diagram rendered from HTML and SVG, near-black page, flat surfaces, few restrained elements, thin strokes, real sans-serif text at film scale, no glow, no neon, no glass, no icons in circles

## Default palette

page #080b12, surface #151b29, text #f2f5fb, teal #42c7a1 for match and pass, amber #f4b353 for warnings only, not-met #ef8f99, attention #e3b878, ok #72d5b8

## Result

Every element is a DOM node with a known position and id, so each lights exactly on its word and carries no generation artefacts; text is HTML (Inter, at least 36 px); a "Design illustration" pill on UI scenes.

## Avoid

A text-heavy page-drawn layout of boxes, columns and lists on a video scene ("a PowerPoint slide on video", rejected outright); glow, neon, glass, generic icons in circles.

## Suits

Suits the UI scenes and process diagrams of a film, where each element must light on its word (UI is never made with image generation), and most slides of a dark deck. As a video background in its page-drawn box layout it reads as a slide deck.
