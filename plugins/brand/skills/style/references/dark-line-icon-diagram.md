# Dark Line Icon Diagram

## Style line

Dark, minimal diagram, smooth radial gradient background from dark at the centre to near-black at the edges, no texture, thin uniform 2 px strokes with rounded caps, icons in one pale cool tone, arrows in a muted accent at 60 percent opacity, one warm accent on one icon only, flat, clean, vector, generous negative space, no text, letters, numbers, words, titles or logos, no gradients on icons, no 3D, no shadows

## Default palette

deep navy radial gradient #101521 to #080b12, icons cool grey #c3cbdb, teal #42c7a1 arrows, amber #f4b353 accent

## Result

Labels added as HTML overlays in the caption-card style. It shares the colour tokens of HTML UI scenes, so it adds no new look to a film that has them.

## Avoid

Thin outlines with empty pillar boxes look flat and bad. Sites and system glyphs arranged around a central agent node (a constellation) were rejected.

## Suits

Suits the process overview of a film that also has HTML UI scenes. The empty-pillar outline form and the constellation layout do not suit explainer films (see Avoid).
