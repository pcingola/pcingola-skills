# Animated Feature 3D

## Style line

Stylised 3D render in the soft look of a modern animated feature film: gently rounded forms, soft global illumination, subtle subsurface skin, clean materials, believable proportions (not chibi, not caricatured)

## Default palette

muted navy, teal and warm amber palette

## Result

No text in the image.

## Avoid

It can read as a consumer ad or a children's film. It adds a third rendering style beside photos and UI scenes.

## Suits

Suits person scenes of a short explainer film that needs a soft, friendly look.
