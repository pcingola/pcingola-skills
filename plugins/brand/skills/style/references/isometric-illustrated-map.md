# Isometric illustrated map

## Style line

Style: isometric flat vector illustration, soft gradients, gentle shading, no outlines, 30-degree isometric perspective, no text, letters, numbers or logos

## Default palette

palette slate blue #587689, light sage #A9D19F, forest green #2F7A5F, terracotta #D9614C, sky blue #5DB3D9, cream #F4EFDB

## Result

Generated as separate parts (a hospital, a room, a person), the first passed as the style reference for the rest, then placed in light zones with vector labels, numbered markers and dashed connectors on top.

## Avoid

Text, letters, numbers and logos in the generated parts; labels are added as vector text.

## Suits

Suits a map of which systems hold which data and how data moves between them, as scene images of an explainer film.
